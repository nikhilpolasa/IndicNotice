# NLP-5 grounded-QA review set v1

This set contains 30 agent-prepared questions over the two real Hindi and
Telugu/English notices used in the NLP-4 smoke run. Every item is
`NEEDS_HUMAN_VERIFICATION`; no item is gold and no QA/retrieval quality score is
reported from it. Candidate answers, evidence IDs and answerability labels are
review targets only.

The set deliberately mixes English, Hindi and Telugu questions and contains
answerable, partial and unanswerable candidates. A human reviewer must inspect
the source PDF/evidence before changing an item to `VERIFIED`.
